# HTTP-API SPM репозитория

HTTP-API SPM репозитория имеет только один эндпоинт, по которому этот репозиторий и определяется. К примеру, эндпоинт
репозитория `fobox.core` - `https://miot.su/repos/fobox.core`

При переходе на этот эндпоинт, возвращается JSON данные со следующими полями:
- `packages` - здесь информация о всех пакетах репозитория
  - `%PACKAGE_NAME%` - здесь информация о каждом отдельном из пакетов репозитория
    - `displayName` - название пакета
    - `author` - имя одного контрибьютора
    - `url` - ссылка, по которой можно скачать `.zip` архив пакета
    - `description` - описание пакета
    - `dependencies` - список зависимостей пакета
    - `version` - версия пакета
      - `major` - старшая версия;
      - `minor` - младшая версия;
      - `patch` - микро изменения;
