# Устройство плагинов

Плагин представляет из себя пакет- каталог или `.zip` архив.

Содержимое плагина должно включать в себя python-модуль в корне пакета.

В `manifest.json` указываются дополнительные поля:
- `zipSafe` - безопасно ли использовать плагин напрямую из `.zip` архива без распаковки;
- `plugin` - настройки плагина:
  - `dispatchers` - диспатчеры плагина. Импортируются из главного python-модуля.

Пример манифеста `core@fobox.core` плагина:
```JSON
{
    "manifestVersion": 1,
    "type": "plugin",
    "displayName": "Core",
    "description": "Core plugin for Fobox",
    "zipSafe": true,
    "version": {
        "major": 1,
        "minor": 0,
        "patch": 6
    },
    "contributors": [
        {
            "name": "Mark Radin",
            "email": "openmiot@gmail.com"
        }
    ],
    "links": [
        {
            "displayName": "GitHub",
            "url": "https://github.com/OpenMiot/fobox"
        }
    ],
    "plugin": {
        "dispatchers": [
            "dp"
        ]
    }
}
```

С примером реализации базового плагина можно ознакомиться [здесь](https://github.com/OpenMiot/slinn2_example_plugin/).
