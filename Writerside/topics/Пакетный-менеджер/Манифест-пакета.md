# Манифест пакета

Любой SPM-пакет должен обязательно содержать в себе файл `manifest.json`

`manifest.json` состоит из следующих полей:

- `manifestVersion` - версия манифеста. _SPM 26.4a_ поддерживает только версию `1`;
- `type` - тип пакета. Может быть:
  - `plugin` для плагина;
  - `template` для шаблона;
- `displayName` - название пакета;
- `description` - описание пакета;
- `version` - версия пакета:
  - `major` - старшая версия;
  - `minor` - младшая версия;
  - `patch` - микро изменения;
- `contributors` - контрибьюторы пакета:
  - `name` - имя контрибьютора;
  - `email` - почта контрибьютора;
- `links` - ссылки:
  - `displayName` - название ссылки;
  - `url` - адрес ссылки.

Также могут быть добавлены дополнительные поля, такие как `plugin`, `template`, `zipSafe`

Пример манифеста пакета `core@fobox.core`:
```JSON
{
    "manifestVersion": 1,
    "type": "plugin",
    "displayName": "Core",
    "description": "Core plugin for Fobox",
    "zipSafe": true,
    "version": {
        "major": 1,
        "minor": 0,
        "patch": 6
    },
    "contributors": [
        {
            "name": "Mark Radin",
            "email": "openmiot@gmail.com"
        }
    ],
    "links": [
        {
            "displayName": "GitHub",
            "url": "https://github.com/OpenMiot/fobox"
        }
    ],
    "plugin": {
        "dispatchers": [
            "dp"
        ]
    }
}
```
