# Устройство шаблонов

Шаблон приложения представляет из себя пакет-каталог с файлами манифеста `manifest.json` и установки `template.py`.

Пример манифеста из пакета `fobox-app@fobox.core`:
```JSON
{
    "manifestVersion": 1,
    "type": "template",
    "displayName": "Fobox app",
    "description": "Fobox app template",
    "version": {
        "major": 1,
        "minor": 0,
        "patch": 1
    },
    "contributors": [
        {
            "name": "Mark Radin",
            "email": "openmiot@gmail.com"
        }
    ],
    "links": [
        {
            "displayName": "GitHub",
            "url": "https://github.com/OpenMiot/fobox"
        }
    ]
}
```

С примером реализации базовго шаблона приложения можно ознакомиться [здесь](https://github.com/OpenMiot/slinn2_example_template/).
