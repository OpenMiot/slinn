# Промежуточная обработка

Для промежуточной обработки запросов используются мидлвари - наследники интерфейса `IMiddleware`.

```Plain Text
Сервер -> Мидлварь1 -> Мидлварь2 -> ... -> МидлварьN -> Обработчик
```

Пример мидлвари:

```Python
from slinn import IMiddleware
from slinn.utils import optional
import functools


class ExampleMiddleware(IMiddleware):
    def __init__(self, message):
        super().__init__()
        self.message = message

    def __call__(self, func):

        @functools.wraps(func)
        async def wrapper(*args, **kwargs):

            self.message = f'ID Пользователя #{kwargs["user_id"]}'
            return await optional(func, *args, **(kwargs|self.__dict__))

        return wrapper

```

Пример использования мидлвари:

```Python
@adp.get('users/<int user_id>')
@ExampleMiddleware()
async def get_user(request: AsyncServer, message: str):
    async request.respond(HttpResponse, message)
```
