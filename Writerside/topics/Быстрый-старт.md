# Быстрый старт

**Slinn** - это серверный асинхронный и синхронный HTTP фреймворк для Python (версии 3.10 и выше)

В этой документации описаны все возможности, рекомендации, особенности фреймворка _Slinn_ и пакетного менеджера _Slinn Package Manager (Далее - SPM)_

_Slinn_ использует MIT лицензию.

Данная документация является частью проекта _Slinn_.

Slinn официально доступен:
- [PYPI](https://pypi.org/project/slinn), а соответственно и из пакетного менеджера pip;
- [Github репозиторий проекта](https://github.com/mrybs/slinn).

Документация актуальна на версию _Slinn 2.3.6_ с _SPM 26.4a_.
