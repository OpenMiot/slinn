# Ответы на запросы

Все ответы на запросы выполняет обработчик.

Вот несколько способов вернуть ответ:

- Обработчик может вернуть экземлпяр класса `TCPResponseChunk` или дочернего:
  ```Python
  async def index(request: AsyncRequest) -> HttpRender:
      return HttpRender('index.ntw3')
  ```
- Обработчик может вернуть часть ответа с помощью генераторов:
    ```Python
    async def index(request: AsyncRequest) -> Generator[HttpResponseHeader, HttpResponseChunk]:
        yield HttpResponseHeader(
            data = [
                ('Content-Length', 22)
            ]
            сontent_type = 'text/html',
            use_gzip = False
        )
        # выполняем работу
        yield HttpResponseChunk('<h1>Hello, world!</h1>')
    ```
- Обработчик может вернуть HTTP-код:
    ```Python
    async def index(request: AsyncRequest) -> int:
        return 404
    ```
    в таком случае ответ будет определяться обработчиком в `hcdp.py` файле.
- Обработчик может ничего не возвращать, но ответить на запрос с помощью метода `Request.respond`:
    ```Python
    async def index(request: AsyncRequest) -> None:
        await request.respond(HttpResponse, '<h1>Hello, world!</h1>')
    ```

Рассмотрим все возможные классы для ответов.
## TCPResponseChunk

Базовый класс ответа. Конструктор принимает в себя полезную нагрузку любого типа, сериализует для передачи по TCP-протоколу

## HttpResponseChunk

Фактически ничем не отличается от `TCPResponseChunk`, нужен для удобства и совместимости

## HttpResponseHeader

Сериализует HTTP-заголовок ответа без тела. Конструктор принимает в себя:
- полезную нагрузку любого типа;
- заголовки в формате списка кортежей - `data`:
    ```Python
    [
        ('Keep-Alive', 'timeout=5, max=1000'),
        ('Connection', 'Keep-Alive')
    ]
    ```
- статус - `status`:
    ```
    403 Forbidden
    ```
- тип контента - `content_type`:
    ```
    application/json
    ```

- флаг для использования gzip - `use_gzip` (по умолчанию `True`)

Задает заголовок `Server: Slinn`.



## HttpResponse

Основной класс ответа.
Конструктор принимает в себя полезную нагрузку (как в `HttpResponseChunk`) и аргументы заголовка (как в `HttpResponseHeader`)

## HttpJSONResponse

Принимает JSON в формате распакованного словаря. Аргументы:
- `__data` вместо `data`;
- `__status` вместо `status`;
- `__content_type` вместо `content_type`.

## HttpRedirect

Выполняет переадресацию со статусом `307 Temporary Redirect` по адресу, переданному единственным аргументом в
конструктор.

## EmptyHttpResponse

Возвращает страницу с пустым контентом и статусом `204 No Content`.

## HttpRender

Возвращает файл в качестве ответа.

Принимает аргументы:
- `file_path` - путь до файла;
- `data` - HTTP-заголовки;
- `status` - HTTP-статус;
- `ppdata` - словарь переменных для препроцессора `Preprocessor`;
- `storage` - объект типа `Storage` или функция `open`, откуда брать файлы.

Запрос рендерится с помощью функций, прописанных в `htrf.py` файле.
