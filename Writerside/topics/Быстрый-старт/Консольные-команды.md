# Консольные команды

## Slinn

В корне проекта с активированным виртуальным окружением:
```Bash
slinn <command>
```
где `<command>`:
- `run` - запустить сервер
- `create-app <app_name> <hosts>` - создать приложение
  - `<app_name` - название приложения
  - `<hosts>` - хосты, на которых работает приложение (синтаксис типа `host=127.0.0.1 host=localhost ...`)
- `delete-app <app_name>` - удалить приложение
  - `<app_name>` - название приложения
- `template <package_name>` - установить шаблон
  - `<package_name` - идентификатор пакета-шаблона
- `template-classic <template_name>` - установить классический шаблон
  - `<template_name>` - идентификатор шаблона
- `migrate-all` - применить все непримененные миграции (которые были найдены)
- `help` - вывести справку со всеми командами
- `version` - вывести используемую версию `Slinn`.

## Slinn Admin

Использование:
```Bash
slinn-admin <command>
```
где `<command>`:
- `create-project <project_name>` - создать проект:
  - `<project_name>` - название проекта;
- `update-project <project_name>` - обновить проект:
  - `<project_name>` - название проекта;
- `help` - вывести справку со всеми командами;
- `version` - вывести используемую версию `Slinn`.

## Slinn Package Manager

В корне проекта с активированным виртуальным окружением:
```Bash
spm <command>
```
где `<command>`:
- `update` - обновить метаданные о пакетах из репозиториев;
- `install <packages>` - установить или обновить пакет:
  - `<packages>` - идентификаторы пакетов через пробел
- `uninstall <packages>` - удалить пакет:
  - `<packages>` - идентификаторы пакетов через пробел
- `info` - вывести информацию о пакете:
  - `<package>` - идентификатор пакета
- `list` - вывести список всех установленных пакетов;
- `list-repos` - вывести список репозииториев;
- `list-packages` - вывести список всех пакетов из репозиториев;
- `help` - вывести справку со всеми командами;
- `version` - вывести используемую версию `SPM`;

Команды `update`, `list-repos`, `list-packages`, `help`, `version` не требуют нахождения в корне проекта, но
активированное виртуальное окружение влияет на используемые репозитории.
