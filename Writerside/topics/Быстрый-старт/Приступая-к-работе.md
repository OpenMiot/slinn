# Приступая к работе

Сперва нам необходимо установить Slinn.
Для этого вам нужен интепретатор Python с установленным модулем pip.

Выполните команду в своем эмуляторе терминала или в командной строке:

```Bash
pip install slinn --break-system-packages
```

Проверьте версию командой:

```Bash
slinn version
```
Выведет что-то вроде `Slinn Nukeful v2.3.9 300726A`

где
- `Slinn` - соответственно название фреймворка;
- `Nukeful` - кодовое название схожих версий. Nukeful, к примеру, для версий 2.3.0 - 2.3.9;
- `2.3.9` - сама версия мажор.минор.выпуск;
- `300726A` - номер выпуска ДДММГГ и в конце буква A-Z для сравнения выпусков одного дня. Также существовали выпуски со строчной буквой.

**Кодовые названия версий**
- Nukeful (2.3.0-2.3.9) - ограниченная поддержка, активное развитие с 7 апреля 2024 по 30 июля 2026. Обладает реализацией протокола HTTP/1.1, добавляет множество возможностей для расширения;
- Murega (2.0.0-2.2.15) - прекращена поддержка с последним корректирующим выпуском 23 февраля 2025, он довольно стабильный, но малофункционален в сравнении с Nukeful;
- Catasm (1.0.0-1.2.1) - прекращена поддержка 5 февраля 2024, однако имеет ряд багов и нереализованных возможностей.

Использовать промежуточные версии не рекомендуется. Но для примера, вот команда для установки пререлиза Nukeful:

```Bash
pip install slinn==2.3.4b0 --break-system-packages --upgrade
```
