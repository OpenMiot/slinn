# Фильтрация запросов

В прошлой статье мы познакомились с двумя фильтрами: `AnyFilter` и `LinkFilter`, а также с особым фильтром `Path`.
Они являются наследниками базового класса `Filter`.

```Python
from slinn import Filter, LinkFilter, AnyFilter, IPath, Path
```

## Filter

Конструктор `Filter` принимает два аргумента - регулярное выражение и список принимаемых HTTP методов.
По умолчанию принимаемые методы - `GET` и `POST`.

Метод `Filter.check` принимает два аргумента - себя ссылку и HTTP метод.
Вернет `True`, если запрос удовлетворяет фильтру.

```Python
filter = Filter('/user/.+/profile.*')
print(filter.check('/user/mrybs/profile?page=about', 'GET'))
# True
print(filter.check('/user/profile/about', 'GET'))
# False
print(any_filter.check('/user/mrybs/profile', 'POST'))
# True
```

Метод `Filter.args` возвращает извлеченные аргументы из ссылки.
`Filter` не реализует этот метод, поэтому он всегда возвращает `{}`,
но, например, `Path` вернет аргументы, извлеченные из ссылки с помощью шаблона в угловых скобках с указанием типа 
(`<ТИП_АРГУМЕНТА(str/int/float/...) НАЗВАНИЕ_АРГУМЕНТА>`).

## LinkFilter

Фильтр `LinkFilter` модифицирует регулярное выражение таким образом, что в начало добавляется `\/?`, в конец - 
`(\/.*)?`, а также все `/` в переданном выражении заменяются на `\/`. 
Это позволяет писать `LinkFilter('users/get')` вместо `Filter('\/users\/get')(\/.*)?`.

```Python
link_filter = LinkFilter('user/.+/profile', ('GET', ))
print(link_filter.check('/user/mrybs/profile?page=about', 'GET'))
# True
print(link_filter.check('/user/profile/about', 'GET'))
# False
print(any_filter.check('/user/mrybs/profile', 'POST'))
# False
```

## AnyFilter
`AnyFilter` является экземпляром класса `Filter`, созданный таким образом, чтобы принимать любые HTTP-запросы с
существующими HTTP-методами.

```Python
print(AnyFilter.check('/user/mrybs/profile?page=about', 'GET'))
# True
print(AnyFilter.check('/user/profile/about', 'GET'))
# True
print(AnyFilter.check('asdfgh', 'TRACE'))
# True
```

## IPath
`IPath` работает не чистыми регулярными выражениями, а с паттернами, которые позволяют извелкать аргументы из ссылки.

```Python
ipath = IPath(r'\/user\/<str user_id>\/profile', ('GET', ))
print(ipath.check('/user/mrybs/profile'), 'GET')
# True
print(ipath.args('/user/001kpp/profile', 'GET'))
# {'user_id': '001kpp'}
print(ipath.check('/user/modiant/about'), 'GET')
# False
```

## Path
`Path` работает не чистыми регулярными выражениями, а с паттернами, которые позволяют извелкать аргументы из ссылки.

```Python
ipath = IPath(r'\/user\/<str user_id>\/profile', ('GET', ))
print(ipath.check('/user/mrybs/profile'), 'GET')
# True
print(ipath.args('/user/001kpp/profile', 'GET'))
# {'user_id': '001kpp'}
print(ipath.check('/user/modiant/about'), 'GET')
# False
```
