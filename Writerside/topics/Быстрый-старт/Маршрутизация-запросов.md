# Маршрутизация запросов

Класс `Dispatcher` используется для управления маршрутизацией запросов.

Подключите его в файл приложения `app.py` и создайте экземлпяр:

```Python
from slinn import Dispatcher

dp = Dispatcher('miot.su')
```

В аргументах к конструктору указывается список адресов, на которых будет работать диспатчер. К примеру, если на 
`31.192.110.142` был совершен HTTP запрос с заголовком `Host: miot.su`, то созданный диспатчер примет этот запрос, а
HTTP запрос с заголовком `Host: id.miot.su` - нет.

Теперь создадим простейший обработчик:

```Python
from slinn import HttpResponse, AnyFilter, AsyncRequest

@dp(AnyFilter)
async def index(request: AsyncRequest) -> HttpResponse:
    await request.respond(HttpResponse, 'Hello, world!')
```

В диспатчер был передан `AnyFilter` - это фильтр, служащий для принятия всех запросов.

Также можно на один обработчик повесить сразу два фильтра:

```Python
from slinn import Render, LinkFilter

@dp(LinkFilter('about'))
@dp(LinkFilter('about.html'))
async def about(request: AsyncRequest) -> HttpResponse:
    await request.respond(Render, 'about.html')
```

`LinkFilter` - еще один фильтр, используемый для принятия запросов по определенной ссылке.

Вместо `Dispatcher` стоит использовать его улучшенную версию `ApiDispatcher`.
Это тот же самый `Dispathcher`, но с CRUD HTTP-методами: `GET`, `POST`, `PATCH`, `PUT`, `DELETE`, `OPTIONS`.
В перечисленных методах используется фильтр `Path`.

Например, вместо предыдущего примера с `ApiDispatcher` можно написать так:

```Python
from slinn import ApiDispatcher

adp = ApiDispatcher()

@adp.get('about')
@adp.get('about.html')
async def about(request: AsyncRequest) -> HttpResponse:
    await request.respond(Render, 'about.html')
```

Также преимущество связки `ApiDispatcher`+`Path` в более простом написании REST-API:
```Python
@adp.get('orders/<int order_id>')
async def get_order(request: AsyncRequest, order_id: int) -> HttpResponse:
    ...
```

Тот же код на `Dispatcher`+`LinkFilter`:

```Python
@dp(LinkFilter('orders/[0-9]+'))
async def get_order(request: AsyncRequest) -> HttpResponse:
    order_id = int(request.link.split('/')[1])
    ...
```
