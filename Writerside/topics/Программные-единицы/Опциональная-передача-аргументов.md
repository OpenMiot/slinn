# Опциональная передача аргументов

Реализована через функцию `slinn.utils.optional(func: Callable, *args, **kwargs)`, где `func` - вызываемая функция, а
`args` и `kwargs` опциональные позиционные и именованные аргументы. 

Аргументы передаются в вызываемую функцию только в том случае, если эта функция принимает эти аргументы.

### Пример

```Python
from slinn.utils import optional


def f(a, b, *, c, d):
    print(a, b, c, d)

optional(
    f,
    a = 1,
    b = 2,
    c = 3,
    d = 4,
    e = 5,
    f = 6
)
```
при запуске выведет:
```
1 2 3 4
```
