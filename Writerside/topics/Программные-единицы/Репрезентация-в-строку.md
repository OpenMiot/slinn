# Репрезентация в строку

Для конвертации любых объектов (в частности — словарей) в строку, используется функция
`slinn.utils.representate_str(obj: Any) -> str`, где `obj` - конвертируемый в строку объект


### Пример

```Python
from slinn.utils import representate_str


print(representate_str(
    {
        'id': 'n_wish',
        'age': 17,
        'family': {
            'mom': 'vika'
        }
    }
))
```
при запуске выведет:
```JSON
{"id":"n_wish","age":17,"family":{"mom":"vika"}}
```
