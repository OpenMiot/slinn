# Быстрый старт

**Slinn** - это универсальная сетевая платформа для Python (версии 3.15 и выше)

В этой документации описаны все возможности, рекомендации, особенности фреймворка _Slinn_ и пакетного менеджера
_Slinn Package Manager (SPM)_

_Slinn_ использует MIT лицензию.

Данная документация является частью проекта _Slinn_.

Slinn официально доступен:
- [PYPI](https://pypi.org/project/slinn), а соответственно и из пакетного менеджера pip;
- [Github репозиторий проекта](https://github.com/mrybs/slinn).

Документация актуальна на версию _Slinn 3.0.0_ с _SPM 26.7-A_.
